## chi tiết Problem B - Subarray Summation Game

### Đề bài nói gì?

Cho mảng A gồm n phần tử **phân biệt**. Cho m cặp (x[i], y[i]).

**Subarray Sum S(A, x, y)** được định nghĩa:

`S(A, x, y) = Σ(i=1 to m) [ Σ(j=x[i] to y[i]) A[j] ]`

Nói nôm na: **với mỗi cặp (x,y), lấy tổng các phần tử từ vị trí x đến y trong mảng A, rồi cộng tất cả lại.**

**Mục tiêu:** Sắp xếp lại mảng A để **S(A,x,y) lớn nhất**, và đếm có **bao nhiêu cách** đạt được giá trị đó.

---

### Tư duy chìa khóa - "Mỗi vị trí được đếm bao nhiêu lần?"

Đây là **insight quan trọng nhất**. Thay vì nghĩ theo từng query, hãy nghĩ:

> **"Vị trí thứ k trong mảng, xuất hiện bao nhiêu lần trong tổng S?"**
> 

### Ví dụ minh họa:

`n=3, queries: (1,2), (2,2), (2,1) → tức là x=[1,2,2], y=[2,2,1]

Vị trí 1: xuất hiện trong query (1,2) → đếm 1 lần
Vị trí 2: xuất hiện trong query (1,2), (2,2), (2,1)? → đếm nhiều lần
Vị trí 3: không xuất hiện trong query nào → đếm 0 lần`

**Gọi cnt[k] = số lần vị trí k xuất hiện trong tất cả các query**

Khi đó:

`S = cnt[1]*A[1] + cnt[2]*A[2] + ... + cnt[n]*A[n]`

---

### Tính cnt[k] hiệu quả - Dùng Difference Array

Với mỗi query (x, y), tất cả vị trí từ x đến y đều tăng thêm 1.

**Nếu dùng brute force:** O(n*m) → quá chậm (n=50000, m=200000)

**Dùng Difference Array:** O(n+m)

python

`diff = [0] * (n+2)

for mỗi query (x, y):
    diff[x] += 1
    diff[y+1] -= 1

# Tính prefix sum để có cnt
cnt[1] = diff[1]
for k in range(2, n+1):
    cnt[k] = cnt[k-1] + diff[k]`

---

### Maximize S - Tham lam (Greedy)

Sau khi có `cnt[k]` cho mỗi vị trí k, ta có:

`S = cnt[1]*A[1] + cnt[2]*A[2] + ... + cnt[n]*A[n]`

Để **maximize tổng này**:

> **Ghép số lớn nhất của A vào vị trí có cnt lớn nhất!**
> 

Đây là bất đẳng thức **rearrangement inequality**: tổng tích lớn nhất khi hai dãy cùng chiều.

### Ví dụ:

`A = [10, 100, 1000]  → sort giảm dần: [1000, 100, 10]
cnt = [3, 2, 1]      → sort giảm dần: [3, 2, 1]

S_max = 1000*3 + 100*2 + 10*1 = 3210`

---

### Đếm số cách

**Trường hợp đơn giản:** Nếu tất cả cnt[k] khác nhau → chỉ có **1 cách** ghép.

**Trường hợp phức tạp:** Nếu có nhiều vị trí có **cùng cnt**, ta có thể **hoán đổi các giá trị A tương ứng** giữa các vị trí có cùng cnt.

Tương tự, nếu nhiều phần tử A có **cùng giá trị** (đề nói phân biệt nên không xảy ra).

### Công thức đếm:

Nhóm các vị trí theo cnt:

- Nhóm cnt=5: có **p** vị trí
- Nhóm cnt=3: có **q** vị trí
- ...

Nhóm các giá trị A theo "rank" (sau khi sort):

- Top **p** giá trị vào nhóm cnt=5 → có **p!** cách sắp xếp nội bộ
- Tiếp **q** giá trị vào nhóm cnt=3 → có **q!** cách

**Tổng số cách = p! × q! × ...**

---

### Code Python hoàn chỉnh

python

`import sys
from math import factorial
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, m = map(int, input().split())
    A = list(map(int, input().split()))
    
    # Difference array để tính cnt
    diff = [0] * (n + 2)
    for _ in range(m):
        x, y = map(int, input().split())
        diff[x] += 1
        if y + 1 <= n:
            diff[y + 1] -= 1
    
    # Tính cnt cho từng vị trí
    cnt = [0] * (n + 1)
    cnt[1] = diff[1]
    for k in range(2, n + 1):
        cnt[k] = cnt[k-1] + diff[k]
    
    cnt_list = cnt[1:]  # cnt[1..n]
    
    # Sort A giảm dần, sort cnt giảm dần
    A.sort(reverse=True)
    cnt_list.sort(reverse=True)
    
    # Tính S_max
    S_max = sum(A[i] * cnt_list[i] for i in range(n))
    
    # Đếm số cách
    # Nhóm cnt_list theo giá trị giống nhau
    ways = 1
    i = 0
    while i < n:
        j = i
        while j < n and cnt_list[j] == cnt_list[i]:
            j += 1
        group_size = j - i
        ways = (ways * factorial(group_size)) % MOD
        i = j
    
    print(S_max, ways)

T = int(input())
for _ in range(T):
    solve()`

---

### 🗺️ Tóm tắt flow tư duy

`Đề bài
   ↓
Nhận ra: S = Σ cnt[k] * A[k]
   ↓
Tính cnt[k] bằng Difference Array  ← O(n+m)
   ↓
Maximize S: sort A↓, sort cnt↓, ghép tham lam  ← Rearrangement inequality
   ↓
Đếm cách: nhóm vị trí cùng cnt → nhân factorial  ← Combinatorics
   ↓
Output S_max và ways % (10^9+7)`

---

### ⚠️ Các lưu ý khi thi

| Vấn đề | Xử lý |
| --- | --- |
| S_max có thể > 2^32 | Dùng `long long` (C++) hoặc Python tự xử lý |
| Số cách rất lớn | Mod 10^9 + 7 |
| n,m lớn | Dùng difference array, không brute force |
| Precompute factorial | Nếu dùng C++, tính trước factorial đến 50000 |
